# Friends Themes

Here you can find themes that have been created for the Friends plugin.

- Default Theme
- Block Theme (shipped since 4.0)
- Google Reader Theme (shipped since 4.0)
- Mastodon Theme (shipped since 4.0)
- [FediPress](https://github.com/alquimidia/fedipress)
- [Asterism](https://github.com/pauljacobson/asterism) — a mobile-first theme based on FediPress, with accessibility and navigation improvements.

## Installing Asterism

Download the plugin ZIP from [Asterism's releases](https://github.com/pauljacobson/asterism/releases), then install and activate it via **Plugins → Add New → Upload Plugin**. Asterism requires WordPress 6.5 or later and PHP 7.4 or later.

In **Friends → Settings**, select **Asterism** under **Frontend → Main Theme** and save. Each user can choose their own theme. Asterism and FediPress can be installed alongside each other.

If you want to create your own theme, take a look at the [wiki page on Writing Themes](https://github.com/akirk/friends/wiki/Writing-Themes).
